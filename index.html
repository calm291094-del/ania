INSTALAR ANIA

Ania puede vivir en tu pantalla de inicio como una app, a pantalla completa y con su propio icono.

01

Android (Chrome): menú (⋮) → «Añadir a pantalla de inicio» o «Instalar aplicación».

02

iPhone (Safari): Compartir (□↑) → «Añadir a pantalla de inicio».

DESPLEGAR EN GITHUB PAGES

Ania empaqueta su propio código en un ZIP listo para subir: incluye index.html, manifest.json, icon.svg, sw.js (caché offline real) y un README con los pasos.

01

Descarga el kit y descomprímelo.

02

Repositorio nuevo en GitHub → Add file → Upload files → arrastra los 5 archivos.

03

Settings → Pages → Branch: main / root → Save.

04

Abre https://tuusuario.github.io/repitorio/ en el móvil e instálala: PWA nativa con modo offline real.
